
# Student Marks Analyzer

## Description
Student Marks Analyzer is a simple Python application that
calculates the total and average marks of a student and
displays the result.

## Features
- Accepts student name and marks
- Calculates total marks
- Calculates average marks
- Displays Pass or Fail

## Technology Used
- Python
- Git
- GitHub

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run the following command:

   python main.py
